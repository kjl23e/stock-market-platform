# Real-Time Stock Market Telemetry & Analytics Platform

An enterprise-grade, event-driven backend platform designed to ingest, process, and analyze high-frequency financial market data in real time using microservices.

## Tech Stack
* **Backend:** Java 17+, Spring Boot, Spring Kafka, Spring Data JPA
* **Streaming & Search:** Apache Kafka, Elasticsearch, Kibana
* **Analytics & Storage:** Apache Spark, AWS S3 (LocalStack)
* **DevOps:** Docker, Docker Compose, GitHub Actions
